# VT-Transformer

**1×1×1 架构的生成式大模型推理框架 —— 由 AI 主导推理代码的生成与优化。**

## 简介

VT-Transformer 是一个面向生成式大模型（LLM）的推理框架，采用 **1×1×1 架构**：每次生成的推理代码只针对

- **一个模型**（如 Qwen2.5-7B）
- **一种硬件**（如 NVIDIA A100 / 华为昇腾 910B）
- **一套部署方案**（量化方案、并行策略、分离部署等）

从而输出**极简、易维护且高效**的推理代码。这种高度特化的代码形态天然适合 AI 自主进行理解、优化与迭代。

## 为什么是 1×1×1？

传统推理框架（如 vLLM、SGLang）普遍采用 **M×N 架构**：同一套代码需要适配 M 种模型 × N 种硬件，并通过大量命令行参数组合来适配不同部署场景。这带来两个问题：

1. **优化困难** —— 通用抽象层掩盖了硬件与模型的具体细节，针对单一场景做深度优化异常困难，即使由 AI 主导也难以完成。
2. **学习成本高** —— 使用这些框架往往需要记忆一长串"命令行参数咒语"，才能正确启动一次推理服务。

VT-Transformer 的答案是反其道而行之：**不做通用框架，只做专用代码**。当 AI 需要为某个具体场景优化推理时，直接生成并迭代一份 1×1×1 的专属实现——没有抽象层的干扰，每一行代码都为当前场景服务。

> **说明**：所谓"一套部署方案"，指量化方案（如 W8A8、FP8）、并行方案（如 TP/PP）、分离方案（如 Prefill-Decode 分离）等部署策略的组合。通常一次部署只需指定其中一套。

## 适用场景

- 需要为特定模型 + 特定硬件榨取极限推理性能的场景
- 希望 AI 自主生成、审查、优化推理代码的工作流
- 偏好可完整阅读、可独立维护的小型代码库，而非庞大通用框架
